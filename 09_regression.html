데이터 분석 모형: 회귀모형(1) — "얼마"를 맞히는 모델

연봉이 지금까지 본 고객보다 훨씬 높은 사람이 오면, 소비액을 얼마로 예측해야 할까?

1부의 분류 모델은 "떠날까, 남을까"를 맞혔어요. 2부는 "얼마"를 맞히는 회귀 모델로 시작합니다. 실제 쇼핑몰 고객 1,000명의 연봉으로 소비액을, 보험 고객 1,338명의 나이로 보험료를 예측하고, 예측이 얼마나 빗나가는지 숫자로 재 봐요.

초파리 연구원

예측은 숫자 하나로 끝나면 안 돼. 얼마나 빗나가는지도 같이 말해야지.

주판봇

비슷한 이웃의 평균을 내면 끝! KNN이 최고야.

시아(인턴)

대결 기준은 처음 보는 고연봉 고객의 소비액 오차(MAE)예요. 낮을수록 좋아요.

모아(인턴)

이웃 평균 대 직선, 결과는 제가 발표할게요!

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을숫자를 맞히는 회귀 모델 세 가지(KNN 회귀, 선형 회귀, 다항 회귀)와 예측 오차를 재는 지표(MSE·RMSE·MAE·R²·수정 R²)를 봅니다.
  2. 왜 중요한가보험료, 대출 금리, 고객의 예상 소비액처럼 금융에서 정해야 하는 숫자는 대부분 "얼마"예요. 그리고 예측의 쓸모는 오차의 크기로 정해집니다.
  3. 업무에서는보험료 산정, 금리 결정, 소비 지출 예측, 마케팅 예산 배분처럼 금액을 정하는 업무에서 회귀 모델로 기준값을 만들고 오차를 함께 보고합니다.

처음이라면 이렇게 읽으세요. 칸마다 ① 가져갈 한 가지 → ② 일상으로 치면 → ③ 실험만 봐도 충분해요. 수식, 자세한 풀이, 업무 팁, 코드는 접어 두었어요(몰라도 됩니다). 직접 돌려 보고 싶다면 이 회차 Colab 실습 노트북을 여세요.

왜 이 주제인가

분류와 회귀

분류는 정해진 칸 중 하나, 회귀는 연속된 숫자를 맞혀요.

모양이 다른 모델

이웃 평균(KNN), 직선(선형), 곡선(다항)은 데이터 밖에서 전혀 다르게 행동해요.

오차의 언어

회귀의 "정확도"는 맞힌 비율이 아니라 빗나간 크기로 말해요.

큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

KNN 회귀 → 선형·비선형 → 지표의 세 걸음과, 실무 사례입니다.

① KNN 회귀

가까운 k명의 값을 평균

② 선형 회귀

데이터를 가장 잘 지나는 직선 y = ax + b

③ 비선형 회귀

제곱 항을 더한 곡선 y = ax² + bx + c

④ 지표

MSE·RMSE·MAE와 R²·수정 R²

1회귀와 KNN 회귀

회귀와 KNN 회귀 — 이웃의 평균으로 금액 맞히기

방법: KNN 회귀 vs 선형 회귀데이터: 쇼핑몰 고객 1,000명 (DirectMarketing)

KNN은 6회차에서 이웃의 다수결로 분류했어요. 회귀에서는 다수결 대신 이웃 값의 평균을 냅니다. 연봉으로 연간 소비액을 맞혀 보세요. "예측할 연봉" 슬라이더를 데이터 밖(170천 달러 이상)으로 옮기면 무슨 일이 생기는지도요.

이 칸에서 가져갈 한 가지

KNN 회귀는 이웃의 평균만 말할 수 있어서, 학습 데이터에서 본 적 없는 범위(외삽)에서는 예측이 멈춘다. 직선은 데이터 밖으로도 이어진다.

왜 이 방법을 쓰나

문제 상황

고객의 연봉을 알면 우리 쇼핑몰에서 1년에 얼마를 쓸지 예측하고 싶어요.

앞 방법의 한계

분류 모델은 "많이 쓴다/적게 쓴다" 같은 칸만 말해요. 정확한 금액이 필요해요.

해법

연봉이 비슷한 이웃 k명의 소비액을 평균 내거나(KNN 회귀), 데이터를 가장 잘 지나는 직선을 그어(선형 회귀) 금액을 예측합니다.

쉽게 말하면 처음 가는 동네의 집값을 어림할 때, 옆집 다섯 채 가격의 평균을 보는 것이 KNN 회귀예요.

일상으로 치면

새 아파트 집값을 어림할 때 비슷한 평형의 이웃 다섯 채 평균을 보면 그럴듯해요. 그런데 그 동네에 없던 100평짜리가 나오면, 이웃 평균은 기껏해야 그 동네 가장 큰 집 가격밖에 말하지 못해요.

데이터 분석으로는

KNN 회귀(KNeighborsRegressor)는 이웃의 평균을, 선형 회귀(LinearRegression)는 직선 y = ax + b를 씁니다. 실제 데이터에서 직선은 소비액 = 22.9 × 연봉(천 달러) − 56였어요. 회귀 모델의 score()는 정확도가 아니라 결정계수 R²를 돌려줘요.

박사

연봉 15만 달러 고객은 얼마를 쓸까요?

주판봇

이웃 평균! KNN이면 다 돼.

초파리 연구원

예측할 연봉을 170 넘게 옮겨 봐. 빨간 곡선이 어떻게 되는지.

조수(하루)

실제 쇼핑몰 고객 300명 표본이에요. 직선은 전체 학습 데이터로 구했어요.

실험 — KNN 회귀와 선형 회귀의 예측 (연봉 → 소비액)

자세한 풀이 — KNN 회귀와 선형 회귀 (펼쳐 보기)
  1. KNN 회귀(k=5)의 시험 R²는 0.40, 학습 R²는 0.60예요. 학습 쪽이 훨씬 높아 과대적합 기미가 있어요.
  2. 선형 회귀의 시험 R²는 0.44, 학습 R²는 0.50로 비슷해요. 연봉 1천 달러가 늘 때 소비액이 약 $22.9 늘어요.
  3. 외삽: 연봉 상위 10%를 빼고 학습하면 KNN 회귀는 아무리 높은 연봉에도 $3,353 이상을 말하지 못해요(실제 평균 $2,417).
  4. 교안 실습(농어 길이 → 무게)도 같은 이유로 KNN 회귀가 큰 농어의 무게를 낮게 예측했어요. 그래서 선형·비선형 회귀로 넘어갑니다.

이 칸의 한계 · R² 0.44는 연봉 하나가 소비액 변동의 44%를 설명한다는 뜻이에요. 나머지 56%는 나이·자녀·구매 이력 등 다른 요인이에요.

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

실무에서 KNN 회귀는 "비슷한 고객의 평균"이라 설명하기 쉬워요. 하지만 신상품·신규 고객층처럼 과거에 없던 범위에서는 쓰면 안 돼요.

외삽은 직선도 위험해요. 직선이 영원히 이어진다는 보장은 없습니다.

현장에 옮기면

예측하려는 고객이 학습 데이터의 범위(최소~최대) 안에 있는지 먼저 확인하는 규칙을 넣어 보세요.

범위 밖 고객은 예측 대신 "검토 필요"로 분류하는 것도 방법이에요.

교안의 파이썬 코드와 예시 코드 (몰라도 됩니다)
from sklearn.neighbors import KNeighborsRegressorKNN 회귀 함수
knr = KNeighborsRegressor().fit(X_train, y_train)기본 k=5로 학습
knr.score(X_test, y_test)회귀의 score는 결정계수 R²
X_train = train_input.reshape(-1, 1)(교안) 특성이 하나여도 2차원 배열로: -1은 행 수 자동, 1은 열 1개

2선형·비선형

선형 회귀와 비선형 회귀 — 직선과 곡선

방법: 최소제곱 직선, 다항(2차·3차) 회귀데이터: 보험 고객 1,338명 (나이 → 보험료)

앞 칸에서 직선이 데이터 밖으로도 이어지는 것을 봤어요. 그런데 데이터가 휘어 있으면요? 보험료는 나이가 들수록 점점 가파르게 오를 수 있어요. 차수를 바꿔 직선과 곡선을 맞춰 보고, 흡연자를 빼면 어떻게 달라지는지 보세요.

이 칸에서 가져갈 한 가지

곡선(다항 회귀)은 제곱 항을 새 특성으로 더한 선형 회귀다. 차수를 올리면 학습 데이터에는 늘 더 잘 맞지만, 시험 데이터에서 함께 좋아질 때만 의미가 있다.

왜 이 방법을 쓰나

문제 상황

보험료가 나이에 따라 어떻게 오르는지 식으로 나타내고 싶어요.

앞 방법의 한계

직선은 "1살 늘 때마다 똑같이 오른다"고 가정해요. 나이가 들수록 가파르게 오르는 관계를 놓쳐요.

해법

나이² 같은 제곱 항을 새 칸으로 더해 곡선을 맞춥니다(다항 회귀). 계수는 여전히 오차 제곱합이 가장 작게 되도록(최소제곱) 찾아요.

쉽게 말하면 자동차가 처음엔 천천히, 갈수록 빨리 가속하면 이동 거리는 직선이 아니라 휘어 올라가는 곡선이 되는 것과 같아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

2차 곡선도 왜 "선형" 회귀라고 해요?

학교 수학으로 보면 중학교 「일차함수」와 「이차함수」예요.

보험료 = a × 나이² + b × 나이 + c
나이²나이를 제곱한 새 칸. 곡선을 만드는 재료
a, b, c데이터에서 찾는 계수
선형계수 a, b, c에 대해서는 여전히 "곱해서 더하기"라서 선형 회귀 도구로 풀 수 있어요
숫자로 한 번 해 보기비흡연자만: 직선 R²보다 2차 곡선 R²가 조금 높음전체 고객: 나이 하나로는 R² ≈ 0.10나이에 나이²를 더해도 거의 그대로 → 흡연을 더하면 0.76

곡선을 아무리 휘어도 흡연 여부라는 중요한 칸이 빠지면 소용없네요. 모양보다 재료가 먼저구나.

일상으로 치면

처음 1초에 1m, 다음 1초에 3m, 그다음 5m… 가는 자동차의 이동 거리는 시간에 대해 휘어 올라가요. 직선으로는 뒤로 갈수록 크게 틀려요.

데이터 분석으로는

교안은 농어 길이와 길이²를 함께 넣어 곡선(비선형) 회귀를 만들었어요. 차수를 너무 올리면 학습 데이터 끝부분에서 곡선이 크게 출렁이는 과대적합이 생겨요. 실제 보험 데이터에서는 나이보다 흡연·비만이 보험료를 훨씬 크게 갈라, 세 개의 띠가 보여요.

실험 — 나이와 보험료: 직선과 곡선

자세한 풀이 — 최소제곱과 차수 (펼쳐 보기)
  1. 최소제곱: 실제값과 예측값의 차이(잔차)를 제곱해 더한 값(SSE)이 가장 작아지는 계수를 찾아요. 선형 회귀의 표준 방법이에요.

  3. 전체 고객은 흡연·비만에 따라 세 띠로 갈라져, 나이만으로는 R²가 0.10에 그쳐요. 차수를 올려도 띠 사이의 차이는 설명하지 못합니다.
  4. 8차 곡선은 학습 R²가 조금 오르지만 시험 R²는 따라오지 않거나 떨어져요. 이것이 회귀의 과대적합이에요.

3성능 지표

회귀의 성능 지표 — 얼마나 빗나갔나

방법: MSE·RMSE·MAE, SST = SSR + SSE, R²·수정 R²데이터: 쇼핑몰 고객 120명

앞 두 칸에서 R²라는 숫자를 계속 봤어요. 이 칸에서는 회귀의 지표를 직접 만들어 봅니다. 기울기와 절편을 움직여 내가 그은 직선의 오차를 재고, 아주 큰 소비 고객 한 명을 넣으면 지표들이 어떻게 반응하는지 보세요.

이 칸에서 가져갈 한 가지

MSE·RMSE는 큰 오차에 민감하고 MAE는 덜 민감하다. R²는 "평균만 쓸 때보다 얼마나 나아졌나"를, 수정 R²는 쓸모없는 특성을 많이 넣은 것을 벌준다.

왜 이 방법을 쓰나

문제 상황

예측이 "얼마나" 빗나가는지 한 숫자로 말하고 싶어요.

앞 방법의 한계

회귀에는 "맞힌 비율"이 없어요. 1원만 틀려도 틀린 거니까요. 오차를 그냥 더하면 +와 −가 서로 지워져요.

해법

오차를 제곱하거나(MSE·RMSE) 절댓값을 취해(MAE) 평균 내고, 평균만 쓴 예측과 비교해 R²를 계산해요.

쉽게 말하면 양궁 점수처럼 과녁 중심에서 얼마나 떨어졌는지로 실력을 재는 거예요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

R²는 어떻게 0에서 1 사이가 돼요?

학교 수학으로 보면 고등학교 「통계」의 분산과 비율이에요.

R² = SSR ÷ SST = 1 − SSE ÷ SST · 수정 R² = 1 − (1 − R²) × (n − 1) ÷ (n − p − 1)
R² (알 스퀘어)결정계수. "모델이 설명한 변동의 비율"을 0~1(시험 데이터에서는 음수도 가능)로
SST총제곱합: 실제값이 평균에서 흩어진 정도(전체 변동)
SSR회귀제곱합: 모델이 설명한 변동
SSE잔차제곱합: 모델이 설명 못 한 변동
n, p데이터 수와 특성 수
숫자로 한 번 해 보기SST = 100, SSE = 56이면R² = 1 − 56 ÷ 100 = 0.44n = 120, p = 10이면 수정 R² = 1 − 0.56 × 119 ÷ 109 ≈ 0.39

평균만 써도 SST만큼 틀리는데, 모델이 그중 44%를 줄였다는 뜻이구나. 특성을 많이 넣으면 수정 R²가 깎이고요.

일상으로 치면

화살이 중심에서 1cm, 1cm, 10cm 떨어졌다면, 평균 거리(MAE)는 4cm지만 제곱해 평균 내면(MSE) 10cm짜리 한 발이 점수를 크게 깎아요. 어느 쪽으로 잴지는 "크게 빗나가는 것이 얼마나 나쁜가"에 달렸어요.

데이터 분석으로는

교안의 지표: MSE(오차² 평균), RMSE(√MSE, 원래 단위), MAE(|오차| 평균), 결정계수 R²와 수정된 결정계수. 관측값의 총변동 SST = 모델이 설명한 SSR + 설명 못 한 SSE의 관계로 R²를 이해해요(학습 데이터의 최소제곱 직선에서 성립).

실험 — 내가 그은 직선의 오차 지표

자세한 풀이 — 지표 고르는 법 (펼쳐 보기)
  1. MSE: 오차를 제곱해 평균. 단위가 제곱(달러²)이라 해석은 어렵지만 수학적으로 다루기 쉬워 학습에 써요.
  2. RMSE: MSE의 제곱근. 원래 단위(달러)라 "평균적으로 약 얼마 빗나간다"고 말할 수 있어요. 큰 오차에 민감해요.
  3. MAE: 오차 절댓값의 평균. 큰 오차 하나에 덜 흔들려 이상치가 있을 때 안정적이에요.
  4. R²: 1이면 완벽, 0이면 평균만 쓴 것과 같음, 음수면 평균보다도 나쁨. 수정 R²는 특성 수 p가 늘수록 벌점을 줘요.

이 칸의 한계 · 지표는 모델끼리 비교하는 도구예요. "RMSE $500이면 충분한가"는 업무(예: 마케팅 예산 오차 허용 범위)가 정해요.

같은 R²라도 데이터의 흩어짐이 다르면 실제 오차 크기는 전혀 달라요.

# Genspark 이미지 지시문 — 실전 #01 코드 구조 일러스트

페이지: `hands_on_01.html`의 **코드 구조 인포그래픽** 자리(맨 위 공통 뼈대 1장 + 코드 A~F 6장).
지금은 직접 그린 작은 도트 아이콘만 있고, 아래 그림을 받으면 각 인포그래픽 맨 위에 자동으로 들어갑니다.

**그림체:** 16비트 RPG풍 픽셀아트(도트), 픽셀이 작고 촘촘한 고해상도. 세밀함 기준 `ref/style_quality_reference.png`를 함께 올립니다. 그림 안에 글자·숫자·로고는 넣지 않습니다.

**구성 원칙:** 그림 한 장 = 코드 하나의 작업 순서. 연구실 바닥에 **보드게임 길처럼 이어진 정거장**을 놓습니다. 정거장은 페이지의 인포그래픽과 같은 순서로 놓습니다(위 줄 왼쪽→오른쪽 3곳, 아래 줄 왼쪽→오른쪽 3곳, 오른쪽 끝에서 아래로 꺾이는 길). 정거장마다 페이지 아이콘과 같은 **커다란 소품**이 있고, 캐릭터가 그 일을 하고 있습니다. 순서는 숫자 대신 **바닥 발판 색**(빨강→주황→노랑→초록→청록→파랑, 공통 뼈대는 보라까지 7색)으로 보여 줍니다.

**요청 순서:** 표지를 참고 그림으로 함께 올려서 ① `1_skel_A_B_C_request.txt`(4장) → ② `2_D_E_F_request.txt`(3장).

## 2. 받은 뒤 넣는 방법

받은 그림을 저장소 루트 `incoming/`에 키 이름 그대로(`h01_ig_skel.png`, `h01_ig_A.png` …) 넣고:
```
cd src && python3 hands_on/add_images_h01.py && python3 hands_on/h01_build.py ..
```

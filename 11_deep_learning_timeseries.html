과거 10일의 주가를 다 보는 모델이 "내일 = 오늘"보다 내일 주가를 잘 맞힐까?

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을인공 신경망의 기본 단위인 뉴런과 딥러닝(RNN·LSTM)의 원리, 시계열 데이터의 특징(추세·계절성·정상성), 그리고 AR·MA·ARIMA 같은 시계열 모델로 실제 주가를 예측해 봅니다.
  2. 왜 중요한가거래량·잔액·주가·환율처럼 금융 데이터의 상당 부분이 시계열이에요. 시간 순서를 무시하고 분석하면 미래 정보를 쓰는 실수(누수)나 가짜 관계에 빠지기 쉬워요.
  3. 업무에서는수요·거래량 예측, 이상 거래 탐지, 리스크 지표 모니터링에 시계열 모델을 쓰고, 복잡한 모델은 늘 "어제 그대로" 같은 단순 기준과 비교해 채택합니다.

처음이라면 이렇게 읽으세요. 칸마다 ① 가져갈 한 가지 → ② 일상으로 치면 → ③ 실험만 봐도 충분해요. 수식, 자세한 풀이, 업무 팁, 코드는 접어 두었어요(몰라도 됩니다). 직접 돌려 보고 싶다면 이 회차 Colab 실습 노트북을 여세요.

왜 이 주제인가

규칙을 다 쓸 수 없다

전통 모델은 사람이 특성을 만들어 줘야 해요. 신경망은 여러 층에서 특성을 스스로 만들어요.

순서가 정보다

오늘의 주가는 어제와 이어져 있어요. 시간 순서를 지켜 학습·시험해야 해요.

단순 기준부터

"내일 = 오늘"이라는 단순한 예측을 이기지 못하면, 복잡한 모델은 쓸 이유가 없어요.

큰 그림 — 이 회차가 흘러가는 4단계 (펼쳐 보기)

뉴런 → 딥러닝 → 시계열 → 예측 모델의 네 걸음입니다.

① 인공 뉴런

입력 × 가중치의 합 → 활성화 함수 → 출력

② 딥러닝

뉴런을 여러 층으로. 순서 데이터는 RNN·LSTM

③ 시계열

추세·계절성·불규칙, 정상 vs 비정상, 차분

④ 예측

AR·MA·ARMA·ARIMA, 시간 순서대로 나눠 평가

1신경망

인공 뉴런에서 딥러닝까지

방법: 퍼셉트론, 활성화 함수, 다층 신경망일상: 여러 신호를 듣고 결정하는 심사역

전통적인 머신러닝은 사람이 "어떤 특성을 볼지"를 정해 줘야 해요. 신경망은 뇌의 신경세포를 흉내 낸 뉴런을 여러 층으로 쌓아 특성을 스스로 만들어요. 먼저 뉴런 하나를 손으로 움직여 보세요.

이 칸에서 가져갈 한 가지

뉴런 하나는 "입력 × 가중치를 더하고 활성화 함수를 통과시킨다"가 전부다. 딥러닝은 이것을 여러 층으로 쌓고, 가중치를 데이터에서 스스로 찾는다.

왜 이 방법을 쓰나

문제 상황

이미지·음성·시계열처럼 사람이 특성을 일일이 만들기 어려운 데이터가 있어요.

앞 방법의 한계

전통 모델은 사람이 만든 특성에 의존하고, 퍼지 모델처럼 규칙(소속도)을 사람이 정하는 방식도 복잡한 패턴에 한계가 있어요.

해법

신경세포를 본뜬 뉴런을 여러 층으로 쌓아, 앞 층의 출력을 다음 층의 입력으로 쓰며 특성을 스스로 만들어요. 가중치는 오차를 줄이는 방향으로 학습해요(역전파·경사하강법).

쉽게 말하면 대출 심사역이 소득·연체·부채 같은 신호에 각각 무게를 달아 합친 뒤, 기준을 넘으면 "위험"이라고 판단하는 것과 같아요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

뉴런 하나의 계산은 로지스틱 회귀와 뭐가 달라요?

학교 수학으로 보면 중학교 「일차식」과 고등학교 「지수함수」예요.

출력 = f(w₁x₁ + w₂x₂ + b), f = 계단·시그모이드·ReLU
x₁, x₂입력(예: 최근 연체 횟수, 소득 — 표준화)
w₁, w₂가중치. 입력의 중요도와 방향
b편향. 기준을 옮김
f활성화 함수. 시그모이드면 로지스틱 회귀와 같은 식
숫자로 한 번 해 보기x₁ = 0.6, x₂ = 0.3, w₁ = 1.5, w₂ = −2.0, b = −0.2z = 1.5 × 0.6 + (−2.0) × 0.3 − 0.2 = 0.10시그모이드 출력 = 1 ÷ (1 + e−0.1) ≈ 0.52

시그모이드 뉴런 하나는 10회차의 로지스틱 회귀랑 똑같은 식이네요! 딥러닝은 이걸 여러 층 쌓은 거구나.

일상으로 치면

심사역은 연체 이력은 무겁게, 소득은 반대 방향으로 따져 합친 뒤 "위험" 여부를 정해요. 신경망은 이런 심사역 수백 명이 층층이 앉아, 앞 줄의 판단을 뒷줄이 다시 종합하는 구조예요.

데이터 분석으로는

교안의 흐름: 신경세포의 자극 전달(수상돌기 → 세포체 → 축삭) → 인공 뉴런(입력 → 가중합 → 활성화 → 출력) → 딥러닝(은닉층이 여러 개). 시계열처럼 순서가 있는 데이터에는 이전 출력이 다시 입력으로 돌아오는 RNN과, 오래된 정보를 선택적으로 기억하는 LSTM을 써요(TensorFlow·Keras).

조수(하루)

가중치는 손으로 정한 예시값이에요. 실제 신경망은 데이터로 학습해요.

실험 — 인공 뉴런 하나 움직여 보기

자세한 풀이 — 뉴런에서 딥러닝, RNN·LSTM까지 (펼쳐 보기)
  1. 활성화 함수: 계단(0 또는 1), 시그모이드(0~1 확률), ReLU(음수는 0, 양수는 그대로). 딥러닝의 은닉층에는 ReLU를 많이 써요.
  2. 다층 신경망: 입력층 → 은닉층 여러 개 → 출력층. 층이 깊어질수록 더 복잡한 특성을 스스로 만들어요.
  3. 학습: 예측 오차(손실)를 줄이는 방향으로 모든 가중치를 조금씩 고쳐요(역전파 + 경사하강법). 신경망 모델은 scikit-learn보다 TensorFlow·Keras·PyTorch로 주로 만들어요.
  4. RNN은 직전 시점의 출력을 다음 입력에 더해 순서를 기억하고, LSTM은 "잊을 것·기억할 것"을 고르는 문(게이트)으로 긴 순서도 다뤄요. 입력은 (샘플 수, 시퀀스 길이, 특성 수)의 3차원 배열이에요.

이 칸의 한계 · 신경망은 데이터가 많고 패턴이 복잡할 때 강하지만, 데이터가 적거나 신호가 약한 금융 시계열에서는 단순 모델보다 나쁜 경우도 많아요(칸 ③과 대결).

업무에 쓸 때 알아 둘 것 (펼쳐 보기)

데이터 분석으로 치면

딥러닝은 이미지(신분증 인식)·음성(콜센터)·텍스트(뉴스 감성 분석) 같은 비정형 데이터에서 특히 강해요.

금융 규제는 "왜 거절했나"를 요구해요. 딥러닝은 설명이 어려워 설명 가능한 AI 기법이 함께 필요해요.

현장에 옮기면

표 형태의 금융 데이터라면 딥러닝 전에 로지스틱 회귀·나무 앙상블로 기준 점수를 먼저 만드세요.

딥러닝이 기준보다 확실히 낫지 않으면 운영 비용(학습·서버·설명)을 감당할 이유가 없어요.

2시계열과 정상성

시계열 데이터 — 평균이 움직이는 데이터

방법: 추세·계절성, 정상·비정상, 차분(수익률)데이터: 아마존·비트코인 일별 종가 2013~2019

앞 칸의 모델들은 데이터가 섞여도 상관없었어요. 시계열은 다릅니다. 순서가 정보이고, 평균이 시간에 따라 움직이기도 해요. 실제 주가를 "가격"과 "하루 변화(수익률)"로 바꿔 가며 네 구간의 평균(빨간 선)을 비교해 보세요.

이 칸에서 가져갈 한 가지

가격은 평균이 계속 움직이는 비정상 시계열이다. 하루 변화(차분, 수익률)로 바꾸면 평균이 0 근처에 머무는 정상 시계열에 가까워지고, 그때 AR·MA 모델을 쓸 수 있다.

왜 이 방법을 쓰나

문제 상황

주가 데이터로 모델을 만들고 싶은데, 그냥 가격을 넣으면 될까요?

앞 방법의 한계

가격은 계속 오르는(또는 내리는) 추세가 있어 평균이 시간마다 달라요. 이런 데이터로 회귀를 하면 함께 오른 두 시계열이 관계 있어 보이는 가짜 회귀에 빠져요.

해법

하루 변화(차분) 또는 수익률로 바꿔 평균을 일정하게 만든 뒤(정상화) 모델링합니다. ARIMA의 I(누적)는 이 차분을 뜻해요.

쉽게 말하면 키가 크는 아이의 키를 그대로 보면 계속 늘지만, "작년보다 몇 cm 컸나"를 보면 비슷한 범위에서 오르내려요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

수익률은 어떻게 계산해요?

학교 수학으로 보면 중학교 「비율」과 고등학교 「로그」예요.

단순 수익률 = (오늘 − 어제) ÷ 어제 · 로그 수익률 = ln(오늘) − ln(어제)
오늘 − 어제차분. 추세(평균의 움직임)를 지움
÷ 어제가격 수준이 달라도 비교할 수 있게 비율로
ln로그 수익률. 작은 변화에서는 단순 수익률과 거의 같음
숫자로 한 번 해 보기아마존 가격 구간 평균: 326 → 1,618 달러로 계속 상승아마존 일간 수익률 구간 평균: 0.05% · 0.21% · 0.13% · 0.15%수익률은 네 구간 모두 0 근처 → 정상성에 가까움

가격은 구간마다 평균이 몇 배씩 다른데, 수익률은 다 0.1% 안팎이네요. 이래서 시계열은 차분부터 하는구나.

일상으로 치면

아이의 키를 매년 재면 늘 커지기만 해서 "평균 키"가 의미가 없어요. 하지만 "1년에 몇 cm 컸나"는 매년 비슷한 범위예요.

데이터 분석으로는

시계열의 특징: 추세(장기 방향), 계절성(정해진 주기의 반복), 순환, 불규칙. 정상 시계열은 평균·분산이 일정하고 자기 자신과의 시차 상관이 시간에 따라 변하지 않아요. 교안은 그래프와 통계 검정(ADF 등)으로 정상·비정상을 구분했어요.

3AR 모델

AR 모델로 주가 예측 — 그리고 "어제 그대로"와 비교

방법: AR(p), MA, ARMA, ARIMA, MAE·MAPE데이터: 아마존·넷플릭스·비트코인 마지막 120거래일

앞 칸에서 시계열의 성질을 봤어요. 이제 예측합니다. AR(p) 모델은 "오늘 가격은 과거 p일 가격의 가중합"이라고 봐요. 과거 며칠을 볼지 바꾸며 예측선을 실제선과 비교하고, 오차를 "어제 가격 그대로"와 견줘 보세요.

이 칸에서 가져갈 한 가지

AR 모델의 예측은 결국 "어제 가격 근처"이고, 과거를 길게 봐도 "내일 = 오늘"보다 잘 맞히지 못했다. 주가가 임의보행에 가깝기 때문이다.

왜 이 방법을 쓰나

문제 상황

내일 주가를 예측해 보고 싶어요.

앞 방법의 한계

시간 순서를 무시한 회귀나 분류는 시계열의 "어제와 이어짐"을 활용하지 못해요.

해법

과거 p일 값을 특성으로 쓰는 AR(p), 과거 예측 오차를 쓰는 MA(q), 둘을 합친 ARMA, 차분까지 넣은 ARIMA로 예측하고, 반드시 시간 순서대로 학습·시험해 단순 기준과 비교합니다.

쉽게 말하면 내일 기온을 예측할 때 "오늘 기온"만 말해도 꽤 맞아요. 모델이 그보다 잘 맞혀야 쓸모가 있어요.

수식이 궁금하면 펼쳐 보기 — 수학 수식을 어려워하는 조수가 대신 물어봅니다

AR(5) 식은 어떻게 생겼어요?

학교 수학으로 보면 중학교 「일차식」이에요. 과거 값들에 무게를 곱해 더하는 가중합입니다.

오늘 = c + φ₁ × 어제 + φ₂ × 그제 + … + φ₅ × 5일 전 + 오차
φ (파이)그리스 문자. 과거 각 날에 곱하는 무게(계수)를 나타냄
φ₁…φₚ과거 각 날의 무게. 데이터로 추정
p (lags)과거 며칠을 볼지
MAE|실제 − 예측|의 평균
MAPE|실제 − 예측| ÷ 실제의 평균(%)
숫자로 한 번 해 보기넷플릭스, 시험 120일: AR(10) MAE = $6.39"내일 = 오늘" MAE = $6.31AR(1) MAE = $6.31 — 사실상 "어제 그대로"와 같은 모델

과거 10일을 다 봐도 어제 가격 하나보다 나을 게 없네요. φ₁이 1에 가깝고 나머지는 0에 가까운 거겠죠?

일상으로 치면

일기예보 없이 "내일도 오늘만큼 덥다"고만 해도 대부분 몇 도 안에 맞아요. 슈퍼컴퓨터 예보가 쓸모 있는 건 이 단순한 기준을 이기기 때문이에요.

교안 실습: yfinance로 페이팔 주가를 받아 2015.9~2024.5로 학습, 2024.6 이후로 시험하며 AutoReg(lags=5)를 만들고 MSE·MAE·MAPE로 평가했어요. MA·ARMA·ARIMA도 같은 방식으로 비교했어요. 이 페이지는 저장소에 들어 있는 fintech-data 주가(2013~2019)로 같은 과정을 밟고, 반드시 "어제 그대로"와 비교합니다.
